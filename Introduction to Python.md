###  Notes
#### <b><u>History of Python</u></b>
- Object-oriented scripting language
- learning curve of python is not steep which makes it useful for data science
- Lots of packages for statistics and data analysis
##### Strengths
- free and open source
- core language is easy to learn
- available on many platforms
##### Weaknesses
- slow for large data sets
- data has to fit in memory
- data type conversion between libraries
	- python lists, NumPy arrays
