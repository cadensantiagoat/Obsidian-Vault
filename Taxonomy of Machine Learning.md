###  Notes
#### <b><u>Taxonomy of Machine Learning</u></b>
Learning can be divided into broad categories based on the following criteria:
- Whether or not they are trained with <u>human supervision</u> (what this class focuses on the most)
	- supervised, unsupervised, semi-supervised, and reinforcement learning
		- supervised is where there is human supervision
		- unsupervised is someone not overseeing training
		- reinforcement learning interacts with the environment and is rewarded for certain actions
- Whether or not they can <u>learn incrementally</u> on new data
	- online versus batch learning
	- learning real time or not
- Whether they work by simply <u>comparing new data points to known data points</u>, or instead by detecting patterns in the training data and <u>building a predictive model</u>, much like scientists do
	- instance-based versus model-based learning
		- **instance-based** compares new data points with an example they've already seen
		- **model-based** is where algorithm itself looks for patterns and it uses those observations to predict future outcomes
#### <b><u>Supervised Learning</u></b>
##### Example of Data
- **input** - the data or information <u>given to an algorithm</u> so it can analyze and learn
- **output** - the final result, score, or prediction <u>generated by the model</u> after processing the input
- **Feature/Feature vectors** are characteristics of what we're looking for a given sample
	- when one sample has multiple features, that's when it becomes a feature vector
- **Label/Class** is the different types of outputs we can have
##### Structure of Dataset
- adding all of the feature/feature vectors and all of the label/classes creates a dataset
- Typically split dataset and give only part of the dataset to the model
	- Training Data
		- Portion of data used to <b><u>train/teach</u></b> the machine learning model
		- Consists of:
			- Train Features
			- Train Labels
	- Testing Data (SHOULD NEVER BE USED DURING TRAINING)
		- Portion of data used to <b><u>test/evaluate</u></b> the performance of a trained machine learning model
		- Consists of:
			- Test Features
			- Test Labels
	- Most important goal of Machine Learning is that we want the model to <b><u>generalize</u></b> its predictions and not just memorize all of the answers
##### Definition
Given a training dataset
- Learn a function or classifier f: X -> Y
	- The process of learning f is called <u>training</u>
- Predict outcomes for a given X(new data):
	- if the learned <u><i>function f</i></u> is used to predict a continuous value, y hat, it's called regression
	- if the learned <u><i>classifier f</i></u> is used
##### Regression
- identifies patterns to predict continuous numerical values
	- Example of regression is weather prediction
##### Classification
- identifies patterns to predict categorical values
	- Example of classification would be marking email as spam or not spam
- **binary classification** is where it's either one or the other
- **multi-class**: each instance still belongs to <u>only one class</u>
	- many possible classes to choose from 
- **multi-label**: each instance can <u>have multiple labels</u> at the same time
- **discretization (binning)** - transforming from numerical to categorical values
	- <u>equal-width intervals</u>: split data into ranges of the exact same size
		- same size intervals
			- splitting a class from ages 0-10, 10-20, 20-30
	- <u>equal-frequency intervals</u>: split data so each group holds roughly same number of items
		- trying to make each interval have the same number of observations
	- <u>custom intervals</u>: split data based on user-defined threshold
##### Classification vs. Regression
- Classification is to find the <u>decision boundary</u> that separates the different groups of data as clearly as possible
	- fines a line, curve or some other boundary that separates class instances
- Regression is to find the <u>function</u> that fits the data the best
##### Supervised learning Methods
- Regression
	- The least-square method
	- Gradient descent
	- K-Nearest Neighbors (KNN), Artificial Neural Network (ANN), Naive Bayes
	- Decision tree, Random forests
- Classification
	- Logistic regression
	- K-Nearest Neighbors (KNN)
	- Artificial Neural Network (ANN), Naive Bayes, Decision tree, Random forests, Support Vector Machines (SVM)
#### <b><u>Unsupervised Learning</u></b>
##### Definition
- Useful when <u>NO labeled data available</u>
	- However, if labeled data is available -> better to use supervised learning
Given any dataset 
- Predict outcomes for a given X(new data):
	- <u>Clusters</u> instances with similar properties: **Clustering**
		- finding which points belong to the same groups
	- <u>Associations</u> instances with high occurrences together: **Association rule mining**
		- finding potential patterns that are hidden
	- <u>Dependencies</u>
		- instances with high correlations or variations: **Feature selection**
##### Applications
- identifying fake news
- object detection, recommendation systems
- identifying fraudulent or criminal activities 
- visualization
Note: in **some applications** we are interested in discovering <u>outliers</u>, not clusters (outlier analysis)
- feature selection - the process of choosing <u>the most useful and relevant input attributes</u> from a dataset to build an efficient machine learning model
##### Association Rule Mining
- predict the occurrence of an item based on the occurrence of other items
##### Unsupervised learning methods
- Clustering
	- partitional clustering
	- hierarchical clustering
- Association Rule Mining
- Feature Selection
